# 架构与安全

Synap 的架构目标是让采集端、传输协议、规则服务和工程接入相互解耦，同时在身份、幂等、隐私和回滚边界上保持明确约束。

## 核心原则

- 外部网络只有安全通信入口，逻辑业务路径不直接暴露。
- 业务消息和网络传输分别维护幂等与顺序标识。
- Agent 默认观察和 fail-open，保护动作受本地版本化规则约束。
- checker、Fact、规则、Kafka topic 和文档共同构成数据契约。
- Synap Build 只生成可审查交付物，不越过目标项目的构建发布流程。
