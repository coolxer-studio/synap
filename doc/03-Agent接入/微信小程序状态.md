# 微信小程序状态

> **当前不可用于新版生产 Server。** 安全通信协议 v1 首发不支持微信小程序。

`synap-agent/agent-miniprogram` 保留源码、历史接入说明和检测用例，但当前构建命令与 `SynapAgent.init()` 会在任何网络请求前明确失败，也不会生成能够连接生产 Server 的旧协议包。

## 运维与接入结论

- 不要把旧明文、旧 codec 或旧 `/sc/h5/**` 路径重新开放给微信小程序。
- 不要将仿真器能够生成 WeChat 样例理解为 Agent 已受支持。
- 不要通过关闭 Server 安全通信来恢复旧小程序连接。
- 产品或项目计划中应将微信小程序标记为“待协议适配”，而不是“实验性可用”。

后续重新启用前至少需要完成：协议 v1 客户端实现、身份与密钥存储设计、平台网络限制验证、构建产物、端到端 ACK/幂等测试、隐私评审和生产升级方案。
