# 数据仿真器

`agent-emulator` 用于生成 Android、iOS、H5、WeChat 和 Host 样例，验证 Server 数据处理与协议样例。它不是生产探针。

## 构建与运行

```bash
cd synap-agent/agent-emulator
go test ./...
go build -o agent-emulator
./agent-emulator --host localhost --device_count 1 --print_log=true
```

仿真器会更新 `guid`、`startId` 和 `clientTime`。请求头格式为：

```text
{guid}-{platform}-{appId}-{sdkVersion}
```

## 使用建议

- 使用独立测试 appId、Kafka topic 或消费标识，避免样例污染生产分析。
- 先验证单设备和单 Fact，再扩大设备数或并发。
- 同时观察 HTTP/ACK、Server 日志、规则结果和 Kafka Checkpoint。
- 用重复 messageId 验证幂等，用 sequence 缺口/倒序验证观察行为。
- WeChat 样例只用于数据契约测试，不表示微信小程序 Agent 当前可接入协议 v1。
