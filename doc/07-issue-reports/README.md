# Issue 归纳报告

本目录保存按需生成的 GitHub / Gitee Issue 归纳报告。报告由 `$synap-issue-workflow` 的 `report` 模式生成，只包含脱敏后的需求摘要、建议修复范围和验收标准。

## 使用流程

1. 在对话中要求“整理 issue”或“生成 issue 报告”。
2. 打开最新时间戳目录中的 `README.md`，分别审核 `github.md` 和 `gitee.md`。
3. 删除整个 Issue 标题块表示不执行；修改“修复范围”和“验收标准”表示按修改后的内容执行。
4. 审核完成后，在对话中明确说“按这份报告修复”。

报告生成阶段不会修改代码、分支、Issue 标签或 Issue 状态。报告位于公开文档目录，不得写入原始对话、diff、日志、token、密码、私钥或带凭据 URL。
