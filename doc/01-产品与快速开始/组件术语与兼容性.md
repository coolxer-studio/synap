# 组件、术语与兼容性

## 核心术语

| 术语 | 含义 |
| --- | --- |
| Agent | 部署在浏览器、主机、应用或移动端的安全探针 |
| Fact | Agent 上报的结构化事实；类型决定字段模型和对应规则 |
| Checker | Server 下发给 Agent 的采集字段、窗口和策略配置 |
| Agenda | 规则命中后形成的风险议题 |
| Punish | 由 Agenda 映射出的客户端动作建议；客户端仍需按本地允许规则执行 |
| Checkpoint | Server 处理后写入 Kafka 的事实与规则结果 |
| messageId | 业务消息的幂等标识；业务重试必须保持不变 |
| seq / requestId | 安全传输层的顺序与请求标识；每次传输重新生成 |
| 信任锚 | Agent 固定的 Server P-256 公钥，用于确认服务端身份 |

## Agent 兼容性

| 平台 | 当前状态 | 推荐接入方式 | 生产注意事项 |
| --- | --- | --- | --- |
| Web / H5 | 支持 | `agent-h5/dist/probe.min.js` | HTTPS、Origin 白名单、公钥固定和 SRI |
| Electron | 支持，复用 H5 | `agent-electron` 的 main / preload / renderer 三入口 | Electron 28+、安全自定义协议、隔离 preload |
| Host | 支持 | `agent-host` 原生二进制 | 首次注册令牌、持久身份目录、系统审计设施 |
| Qt | 支持，复用 Host | `agent-qt` CMake/qmake SDK | Qt 5.15/6.x、OpenSSL、应用内轻量采集 |
| Spring Boot | 支持 | Starter + Java Agent | Java 17、Spring Boot 3.2–3.x、持久 spool |
| Android | 支持 | `agent-android` | 协议 v1、注册令牌、ACK 幂等和 240 KiB 分批 |
| iOS | 有条件联调 | `agent-ios` | 已接入协议 v1；当前 upload 尚未完成 Android 同等级 ACK/队列语义 |
| HarmonyOS NEXT | 客户端完成，Server 待适配 | `agent-harmony` HAR | API 12+；当前 Server 未注册 `HARMONY/harmony` |
| ESP32 / C3 / S3 | 客户端完成，Server 待适配 | `agent-esp32` component | ESP-IDF 5.5.1；当前 Server 无 `esp32` checker/Fact |
| Emulator | 联调工具 | `agent-emulator` | 不作为生产探针 |
| 微信小程序 | **当前禁用** | 无 | 构建和初始化会在发起网络请求前失败 |

## 服务依赖

| 组件 | 必需条件 |
| --- | --- |
| Synap Server | Java 17、Kafka；生产幂等与安全会话需要 Redis |
| Synap Build | Go 1.23+、Git、至少一个已安装并登录的 Synap Build 执行器 |
| 文档中心 | 任意静态 HTTP 服务；浏览器需要访问 jsDelivr 加载 Docsify |

> 各子项目可能处于不同版本周期。本文档不声明统一产品版本，发布时应同时记录 Server、Agent、规则配置和安全通信 SDK 的实际版本。
