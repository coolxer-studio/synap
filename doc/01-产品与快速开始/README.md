# 产品与快速开始

Synap 将“采集、传输、规则、交付”拆成可独立部署和演进的组件，同时通过稳定的 Fact、ACK 与安全通信契约协作。

## 适合的场景

- 浏览器和 WebView 的运行环境、自动化与异常交互观测。
- Linux、Windows、macOS 主机资产采集和持续审计事件接入。
- Spring Boot API 资产、运行时配置和危险 Sink 观测。
- Android 客户端接入，以及 iOS 当前安全传输/ACK 差异的条件联调。
- Electron、Qt 桌面接入；HarmonyOS 与 ESP32 的服务端待适配评估。
- 使用受控 AI 工程任务将探针 SDK 接入目标仓库。

## 不替代什么

- 不替代 TLS、WAF、EDR、SIEM 或业务鉴权体系。
- 观察规则默认不应被理解为确定性攻击判定；风险需要结合证据、版本和置信度处理。
- Synap Build 不负责目标工程的构建、测试、提交、推送或生产发布。
- 微信小程序源码当前仅保留作历史和后续适配基础，协议 v1 首版不可用。
