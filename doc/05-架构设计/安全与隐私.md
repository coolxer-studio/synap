# 安全与隐私

## 网络与身份

- 所有生产 Agent 通过 TLS 1.2+ 访问 `/sc/v1/**`。
- H5、Host、Android 与 Spring Boot 的当前客户端校验也接受 HTTP；这只是实现兼容范围，
  不是生产降级建议。应用层密文不能隐藏目标地址、连接元数据，也不能替代 TLS 证书验证。
- Agent 固定 Server P-256 公钥；验证失败不回退明文。
- 原生设备使用单次注册令牌，H5 使用 Origin、公钥固定与不可导出浏览器身份。
- 可信代理只配置真实网关 CIDR，来自其他来源的转发头全部忽略。

## 密钥管理

- 私钥、会话记录密钥、管理令牌和 Build Token 不进入 Git、镜像、普通日志或任务参数。
- 身份密钥跨重启稳定，轮换采用“先新增信任、再切换身份、最后移除旧锚”的顺序。
- Agent 身份文件和 spool 目录仅允许运行账号访问；禁止克隆到其他设备。
- Synap Build 控制台写盘前执行凭据脱敏与公开执行器身份映射。

## 最小采集

- H5 上传时间窗口统计，不上传输入内容或完整轨迹。
- Spring Boot 默认不上传 Cookie、Authorization、Session ID、原始 query、正文或完整堆栈。
- 客户端和业务 API 禁止提交密码、Token、支付卡和身份证明原值。
- Host 只读已部署审计设施，核心业务目录默认空，必须由部署方显式配置。

部署方仍需完成数据分类、用户告知、合法性评估、访问控制、保留和删除策略。技术上的“不采集某字段”不能替代组织层面的隐私治理。

## 风险与保护

新规则默认观察，风险结果包含 reason code、证据数量和置信度。Spring Boot `protect` 只执行本地内置且显式启用的版本化规则；Server 无权下发任意代码或表达式。

## Synap Build 边界

- 仓库必须命中白名单。
- 当前端点模板只允许仓库读写，不授予网络、任意 shell、外部目录、子代理、提交或推送。
- 固定 SDK 资源只读，并从 diff 和交付包排除。
- 交付包属于待审查输入，不能未经测试直接发布。
