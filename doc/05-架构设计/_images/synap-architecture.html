Agent 运行时流程
enroll(token) → handshake → /attach/start → 收到 config + agenda → collect → spool → /attach/upload (batch) → ACK → 清除/重试队列
传输层 — 安全通信协议 v1
密文信封：业务 method/path/header/body 全部在密文内
POST /sc/v1/handshake
POST /sc/v1/handshake/finish
POST /sc/v1/message
P-256 ECDH · HKDF-SHA256 · AES-256-GCM · Agent 固定 Server SPKI 信任锚 · 外层 requestId 经 AAD 认证
SecureRouteEnforcementFilter
拦截 /attach/* /cross/* /1/* /2/* /risk/* — 明文直连返回 404，仅放行 sc1-authenticated 请求

响应回传 — Agent 收到后处理本地队列
start → checker config + agenda + punish + risk
upload → UploadAck (accepted / duplicate / rejected) + agenda + punish
cross → 业务查询结果
ACK = accepted → 清除消息
ACK = duplicate → 清除消息
ACK = rejected(retryable) → 重试
ACK = rejected → 死信
HTTP 429/5xx → 保留重试
