# 子项目开发

## Synap Server

```bash
cd synap-server
mvn test
mvn spring-boot:run
```

核心位置：

```text
src/main/java/com/coolxer/controller   HTTP 与逻辑接口
src/main/java/com/coolxer/model        Fact、Agenda、Punish 等模型
src/main/java/com/coolxer/service      配置、规则和跨服务逻辑
src/main/java/com/coolxer/rule         Groovy 规则
src/main/resources/checker_config      平台 checker
```

## H5 Agent

```bash
cd synap-agent/agent-h5
npm ci
npm run ci
```

检查生产包、SRI 摘要、协议 SDK 版本和敏感信息扫描结果。

## Electron Agent

```bash
cd synap-agent/agent-electron
npm ci
npm run ci
```

同时验证 main sender/Origin 校验、preload 暴露面、renderer 与 H5 的 Fact 兼容性，
以及安全自定义协议下的真实 Electron 冒烟用例。

## Host Agent

在 `synap-agent/agent-host` 中使用 Makefile 和目标平台部署材料。变更审计能力时同时验证 Linux、Windows、macOS 的 capability/degraded 行为和权限边界。

## Qt Agent

```bash
cd synap-agent/agent-qt
cmake -S . -B build -DSYNAP_AGENT_QT_BUILD_TESTS=ON
cmake --build build
ctest --test-dir build --output-on-failure
```

同时验证 Qt 5.15/6.x、CMake/qmake 集成、Host Fact 兼容、UI 非阻塞和身份/队列目录权限。

## Android 与 iOS Agent

Android 变更需验证 Gradle 单元测试、真机初始化、240 KiB 分批、ACK 分类、公网 IP 回退和
进程内队列限制。iOS 当前需特别核对 upload `meta`、Fact 顺序字段、Server ACK 客户端集合
与失败重入队；未补齐前不要把安全传输测试等同于至少一次业务传输验收。

## HarmonyOS Agent

```bash
cd synap-agent/agent-harmony
node tools/verify-project.mjs
```

有 API 12+ SDK 时再运行 HAR、HAP 和 ohosTest 构建。客户端变更不能绕过当前 Server
`HARMONY/harmony` 待适配状态。

## ESP32 Agent

```bash
cd synap-agent/agent-esp32
python -m pytest -q test
```

使用 ESP-IDF 5.5.1 分别编译 esp32、esp32c3、esp32s3。生产 defaults、eFuse、NVS key
和每设备 manifest 只能在受控量产流水线验证；Server 适配前只连接本地协议桩。

## Spring Boot Agent

```bash
cd synap-agent/agent-springboot
mvn verify
```

需要同时验证 Starter-only、JavaAgent-only、完整模式、observe、protect 和 fail-open。

## Emulator

```bash
cd synap-agent/agent-emulator
go test ./...
go build -o agent-emulator
```

## Synap Build

```bash
cd synap-build
node --check internal/assets/web/app.js
go test ./...
go vet ./...
```

公共 API 变更必须同步 OpenAPI、README、HTTP 测试和前端调用；配置变更必须同步 `.env.example`、README 与配置测试。
