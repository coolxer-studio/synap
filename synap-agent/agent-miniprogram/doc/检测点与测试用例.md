# 微信小程序检测点与测试用例

本版本不支持微信小程序连接安全协议 v1；以下检测点只作为后续迁移设计资料，不是可发布契约。

| Fact | 监听/检测内容 | 默认 | 关键隐私约束 |
| --- | --- | --- | --- |
| DeviceData | 设备、窗口、系统设置、电池、网络、能力状态 | low | 每个 startId 一次；权限和内网地址默认关闭 |
| SelfAppData | appId、版本、envVersion、基础库、scene、referrer appId、路径模板 | low | 删除 query、extraData |
| RuntimeData | 开发者工具、enableDebug、非 release、scene=1030、代码格式化标签 | low | 单信号仅 LOW |
| IntegrityData | appKeyId/endpoint/档位变化，wx.request、设备和监听 API 变化 | low | 多信号加权，宿主改写不单独判高风险 |
| SessionData | show/hide、路由、网络变化、时钟回拨、内存告警、会话时长 | low | 不采集页面参数 |
| ErrorData | onError、UnhandledRejection、PageNotFound、SDK 请求错误 | low | 5 秒同指纹合并；无原始堆栈 |
| DebugData | 前台主线程长暂停边沿 | low | 30 秒冷却，LOW 观察信号 |
| BehaviorData | 宿主显式传入的点击、触摸、输入节奏与轨迹摘要 | low | 无 value、dataset、完整轨迹 |
| ActionData | 登录/提交/支付动作阶段与短窗口计数 | 显式 API | 不接收业务字段值 |
| NetworkData | request/upload/download/socket 路径模板、次数、失败、耗时 | full | 排除 SDK 接口，无 query/body/header |
| LocationData | 已授权时一次性位置、精度和速度 | full | 不主动持续跟踪 |
| UserData | 受限、脱敏的业务上下文 | 显式 API | 32 KiB 上限和敏感键拒绝 |

## 手工测试用例

1. 正常真机：使用 `low` 启动 60 秒。预期无权限弹窗，Device/SelfApp 各一条，内外网 IP 无 `0.0.0.0`。
2. 开发者工具：在微信开发者工具启动。预期 `devtools=true`，服务端出现 `微信观察-开发者工具` LOW，不出现 HIGH。
3. 代码格式化：开发构建或注入带换行的格式化探针函数。预期 `codeFormatting=1`，标签 `微信观察-代码格式化`，reason code `CODE_FORMATTING_DETECTED`。
4. 调试长暂停：点击 Demo“调试长暂停检测”。预期前台暂停超过阈值后产生 DebugData；30 秒内不重复。
5. API 篡改：初始化后替换 `wx.getDeviceInfo` 或 `wx.request`，等待完整性周期。预期出现变化信号；一个信号 LOW，至少两个独立高权重信号才允许 MEDIUM。
6. 错误合并：5 秒内触发相同错误 5 次。预期只上传一条 ErrorData、`count=5`，无 stack/query/token/手机号/邮箱。
7. 行为聚合：调用 `trackInteraction` 至少 20 次，传入包含 `detail.value` 和 dataset 的事件。预期 BehaviorData 不包含这些字段；至少两类统计异常才为 MEDIUM。
8. 前后台：连续 hide/show 后检查 SessionData。预期后台暂停行为和周期采集，恢复后开始新行为窗口。
9. 离线恢复：上报中断网并刷新。预期原 messageId、sequence、sessionId、common 保持不变；联网后 ACK，不重复规则/Kafka。
10. 部分 ACK：服务端只 accepted 一部分并永久拒绝一条。预期只重试未确认且可重试项，上报期间新入队消息不被清除。
11. 位置：`low` 下无 getLocation；`full` 但未授权仍不弹窗；已授权时仅采集一次并携带 accuracy/status。
12. 销毁：调用 `destroy({flush:false})`。预期 timer/listener/RequestTask 为 0，后续不产生 Fact。

## 自动化命令

```bash
npm run lint
npm test
npm run build:prod
npm run size
```

服务端规则与协议回归使用 JDK 17：

```bash
JAVA_HOME=/path/to/jdk17 mvn test
```
