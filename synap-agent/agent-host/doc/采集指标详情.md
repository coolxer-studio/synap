# Host 采集指标

探针上报 `DeviceData`、`FileData`、`RuntimeData`、`NetData`、`EventData`，字段顺序严格采用 server `checker_config/host.json`。

- Device：系统、内核、型号、厂商、CPU、内存、磁盘、电池、主网卡、掩码和广播地址。屏幕或电池不可用时为空。
- File：存在性、受限长度的文件内容、目录正则列表、MD5 和可读性。YARA 默认关闭，但保留等长协议位置。
- Runtime：正则命中的进程、指定环境变量、无 shell 的受限命令输出。
- Net：本机监听端口、Unix socket、接口、代理环境、hosts 匹配项和证书占位。
- Event：Linux 可读取 auth.log/secure 时，最多采集 256 条真实成功 SSH 登录；Windows/macOS 当前无可靠权限无关来源时返回空数组。

每个字符串字段最多 64 KiB，单次 HTTP envelope 最大 256 KiB。超限 Fact 会跳过并输出不含敏感内容的告警。
