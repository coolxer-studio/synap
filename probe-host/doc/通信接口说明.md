## 3.命令行接口

### 3.1启动接口

命令：

```shell
./bin/probe --start_with_key <key>
```

内部说明：

> 后台进程持续运行，需要调用启动接口和上传接口
> 本次需要做多次启动判断，如果已经启动了，在其运行命令不再启动新的进程，直接错误结束
> 暂时不做key的认证，空着即可

### 3.2添加用户信息接口

命令：

```
./bin/probe --user_data "{'user_name':'admin','id_card':'xxxxxx'}" --user_id "xxxxxx"
```

内部说明：

> 将命令行参数的数据放到上传消息的队列中即可
>
> 格式：{'tyep':'UserData','data':<user_data>,'userId':<user_id>}

### 3.3查询设备信息接口
命令：

```
./bin/probe --device_info
```

内部说明：

> 调用接口获取：/2/1 （按照start接口格式，只修改接口url）

### 3.4查询风险等级接口

命令：

```
./bin/probe --rating
```

内部说明：

> 调用接口获取：/2/6 （按照start接口格式，只修改接口url）

### 3.5查询标签接口

