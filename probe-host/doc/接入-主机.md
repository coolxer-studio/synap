# 主机接入

## SDK说明
- sdk下载：http://sdk.genie.coolxer.com  
- sdk 目录说明
```
├── doc [文档]  
│   └── 接入-主机.md  
├── amd64 [x86架构]  
│   └── x-probe [可执行程序] 
├── arm64 [arm架构]  
│   └── x-probe [可执行程序] 
```
- 当前是以运行可执行程序的方式集成到系统中使用，后续将支持不同语言框架的集成SDK。

## 集成步骤

**第一步：** 拷贝可执行文件到项目工程

将可执行文件拷贝到项目任意位置中，比如./bin目录下： 

**第一步：** 初始化sdk，集成结束  

在app启动的时候以命令行形式运行可执行文件x-probe

python代码示例：

```
import subprocess

command = "./bin/x-probe"

# 使用 subprocess.Popen 启动后台任务
# 添加 shell=True 参数以便运行命令
# 如果需要将输出重定向到文件，请使用 stdout 和 stderr 参数
# 例如：subprocess.Popen(command, shell=True, stdout=open('output.txt', 'w'), stderr=open('error.txt', 'w'))

subprocess.Popen(command, shell=True)
```

java代码示例：

```
import java.io.IOException;

public class RunBackgroundTask {
    public static void main(String[] args) {
        try {
            String command = "./bin/x-probe";

            // 使用 ProcessBuilder 启动后台任务
            ProcessBuilder processBuilder = new ProcessBuilder(command);
            
            // 将命令的标准输出和标准错误输出重定向到文件
            // processBuilder.redirectOutput(new File("output.txt"));
            // processBuilder.redirectError(new File("error.txt"));
            
            // 启动命令并等待它完成
            Process process = processBuilder.start();
            
            // 检查命令的返回代码（0 表示成功）
            int exitCode = process.waitFor();
            
            if (exitCode == 0) {
                System.out.println("命令成功执行。");
            } else {
                System.err.println("命令执行失败，返回代码：" + exitCode);
            }
        } catch (IOException | InterruptedException e) {
            e.printStackTrace();
        }
    }
}
```



## 验证

三种方式验证：

1.初始化成功后：日志输出：is init probe:true

2.通过抓包可以看到发送密文数据到指定的服务器

3.登录web平台查看运行详情可以看到有运行数据上送 

 

##  接口定义

以命令行形式运行可执行文件x-probe，实现接口调用   
### 1.启动程序

**接口命令：**  
`./x-probe`

**示例：**  
```
$ ./x-probe
开始启动...
is init probe:true!
```
### 2.发送用户数据

**接口命令：**  
`./x-probe data -i {userId} -d {userData}`

**示例：**  
```
./x-probe data -i userxxxId -d {\"user_name\":\"sansan\"}

```
