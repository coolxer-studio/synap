# H5 安全探针检测点与测试用例

本文档描述 `synap-agent-h5 1.3.0` 第一版当前实现的通信契约、默认采集范围、检测标签、隐私边界和验收方法。设备、评级和标签查询统一使用 Promise API。

## 第一版通信契约

SDK 使用 `@coolxer/secure-communication-js@1.0.0`。浏览器外层只访问
`/sc/v1/handshake`、`/sc/v1/handshake/finish` 和 `/sc/v1/message`；下表路径是
AEAD 密文内的逻辑路由：

| 方法 | 接口 | 用途 |
| --- | --- | --- |
| POST | `/attach/start` | 获取采集策略并启动探针 |
| POST | `/attach/upload` | 批量上报 Fact 并接收 ACK |
| POST | `/cross/info` | 查询设备信息 |
| POST | `/cross/rating` | 查询风险评级 |
| POST | `/cross/label_start` | 查询本次启动标签 |

start 的 `meta` 包含稳定的 `messageId/batchId/sessionId/createdAt/observedAt`、固定 `sequence=1` 和递增 `attempt`。upload 的 `meta.protocolVersion` 固定为 `1`，并包含 `batchId/sessionId/attempt/createdAt/appKeyId/detectorVersion`。普通消息从 `sequence=2` 开始，并包含稳定的 `messageId` 和毫秒级 `observedAt`；StartData 未确认前暂缓 upload。

客户端只有在成功解码响应、`status=1`、ACK 存在且 `ack.batchId` 一致时才提交批次。已接受或已判重的消息从队列删除；未确认和可重试消息恢复到队首并指数退避。传输语义是“至少一次传输 + messageId 幂等消费”，不是网络层 exactly-once。

## 默认采集档位

默认使用低侵入 `low` 档位：

| 能力 | 默认值 | 说明 |
| --- | --- | --- |
| Canvas / WebGL / 字体 | 关闭 | 高熵指纹，仅由宿主显式开启 |
| WebRTC 内网地址 | 关闭 | 不请求第三方 STUN；开启后只读取 host candidate |
| 精确位置 | 关闭 | 默认不请求位置权限 |
| 行为聚合 | 开启 | 按动画帧采样，每 10 秒生成统计摘要 |
| 连续原始轨迹 | 关闭 | 不上传完整鼠标、触摸轨迹；仍保留页面、点击和输入类型事件 |
| 调试行为 | 开启 | 低权重观察 DevTools 快捷键、窗口尺寸边沿和主线程长暂停 |
| 环境完整性 | 开启 | 多信号加权，单一信号不直接判高风险 |
| 会话检测 | 开启 | 可见性、焦点、BFCache、时钟和多标签页 |
| 业务网络监控 | 关闭 | 显式开启后仅上传路径模板和汇总指标 |
| UA-CH 高熵值 | 关闭 | 仅在安全上下文且宿主显式开启时读取 |
| 浏览器安全报告 | 开启 | CSP、资源加载错误和 ReportingObserver 脱敏聚合 |
| 资源与宿主完整性 | 开启 | SDK 来源、SRI、iframe、Service Worker 等 |

`balanced` 额外打开 Canvas、WebGL 和字体；`full` 打开全部开关；`minimal` 关闭所有可选采集，包括调试行为。

## 可监听和检测的内容

| Fact / 服务端信号 | 默认 | 采集或判断内容 | 上报时机 |
| --- | --- | --- | --- |
| `DeviceData` | 开启 | 系统、浏览器、屏幕、CPU、存储、电池、网络、能力状态及可选高熵指纹 | 每个 `startId` 一次 |
| `SelfAppData` | 开启 | 当前页面 origin/域名与应用域名配置 | 初始化一次，发生变化再报 |
| `RuntimeData` | 开启 | 代码格式化标记、WebView 运行类型、webdriver/PhantomJS/Selenium 等自动化特征 | 初始化一次，结果变化再报 |
| `IntegrityData` | 开启 | UA/UA-CH/platform/language/touch/screen 一致性，关键 API、appKey 和策略篡改 | 初始化及周期检查，变化才报 |
| `ResourceIntegrityData` | 开启 | SDK 来源、SRI、iframe/ancestor、Service Worker、CSP/Permissions Policy、导航和安全报告 | 初始化、变化或 10 秒聚合 |
| `BehaviorData` | 开启 | 事件数、速度/加速度、方向、直线比例、停顿、时间熵、点击/输入节奏、可信事件数 | 有行为时每 10 秒一条 |
| `EventData` | 开启 | `pageshow/pagehide/click/input` 的脱敏事件数据；不采集输入值 | 事件发生时；触摸兼容点击会合并 |
| `SessionData` | 开启 | visibility、focus、online、BFCache、时钟回拨/漂移、并发标签页 | 初始化和状态变化时 |
| `ErrorData` | 开启 | JS 异常、Promise 拒绝、资源失败、CSP 违规的脱敏摘要 | 同指纹 5 秒合并后上报 |
| `DebugData` | 开启 | 可见页面主线程相对定时器长暂停 | 状态边沿触发 |
| `DevToolData` | 开启 | F12、Ctrl/Command+Alt+I 和窗口内外尺寸差 | 快捷键或尺寸状态边沿触发 |
| `ActionData` | 按调用 | 登录、提交、支付等业务动作短窗口内的行为计数 | `markAction` 完成阶段 |
| `UserData` | 按调用 | 脱敏用户标识及不超过 32 KiB 的业务上下文 | `userData` 调用时 |
| `LocationData` | 关闭 | 显式授权后的一次性位置、权限状态、精度和速度等 | 首次取得有效坐标；后续状态更新达到 100 米、50 米精度差或 60 秒阈值才重报 |
| `NetworkData` | 关闭 | fetch/XHR/Beacon/WebSocket/EventSource/资源加载的路径模板、状态组、耗时、失败数 | 有数据时每 10 秒聚合 |
| HTTP/网关信号 | 服务端 | 来源 IP、可信代理链、请求 UA、Origin/Referer、Fetch Metadata、ASN、网络类型、TLS 指纹、IP 信誉 | 每次请求 |
| 消息与会话状态 | 服务端 | messageId 判重、sequence 缺口/倒序、客户端与服务端时间差、账号设备/IP/ASN/并发会话变化 | 每条消息 |

浏览器能力缺失、被策略禁用、被浏览器阻止、采集错误和被隐私机制遮蔽，分别使用 `unavailable/disabled/blocked/error/masked` 表示；单纯“不支持”不应被视为风险。

## 调试和代码格式化标签

### 调试行为

`low` 默认启用调试观察：

- F12 或 Ctrl/Command+Alt+I 生成 `DevToolData`。
- `outerWidth/innerWidth` 或 `outerHeight/innerHeight` 差值越过 200 像素时生成 `DevToolData`。
- 页面可见时，10 秒定时器出现超过 5 秒的额外漂移会生成 `DebugData`。

服务端分别生成 `H5观察-开发工具` 和 `H5观察-调试暂停`，级别均为 `LOW`。这些条件也可能由浏览器布局、系统停顿或用户正常操作造成，只能作为低权重辅助证据。

### 代码格式化

`RuntimeData.custom.format` 的含义如下：

| 值 | 含义 | 服务端结果 |
| --- | --- | --- |
| `1` / `true` | 探针运行函数源码中识别到换行格式 | `H5观察-代码格式化`，`LOW`，reason code 为 `CODE_FORMATTING_DETECTED` |
| `0` / `false` | 未识别到该格式特征 | 不生成代码格式化标签 |

该信号用于识别产物被重新格式化、重写或以非预期形态执行的迹象。DevTools 的 Pretty print 通常只改变显示，不一定改变 `Function.prototype.toString()` 结果，因此不能保证触发。源码完整性应以 HTTPS、固定发布产物和 SHA-384 SRI 为主，格式化标签仅作为观察证据。

## ErrorData 具体内容

`ErrorData` 收集的是可用于聚合和归因的脱敏错误摘要，不是原始错误对象或完整堆栈。

| 字段 | 说明 |
| --- | --- |
| `type` | 固定为 `ErrorData` |
| `buildDate` | SDK 构建消息的时间 |
| `from` | `windowError`、`unhandledRejection`、`resourceError` 或 `securityPolicyViolation` |
| `category` | `script`、`promise`、`resource` 或 `csp` |
| `message` | 最长 256 字符的模板化、脱敏错误摘要 |
| `templateHash` | `category/message/source/line/column` 指纹的 FNV-1a 摘要 |
| `source` | 只保留 origin 和路径模板的资源地址 |
| `lineno` / `colno` | 脚本错误的行、列；不可用时为 `0` |
| `count` | 同指纹在 5 秒窗口内出现的次数 |
| `messageId/sequence/observedAt` | 入队时统一补充的消息元数据 |

错误来源包括：

- `window` JS 运行时错误；
- 未处理的 Promise rejection；
- script、img、link 等资源加载失败；
- CSP `securitypolicyviolation`。

SDK 不上传 `Error` 对象、堆栈、完整 `console.error` 参数、URL query/fragment、请求 body/header/cookie、表单值或按键内容。Bearer token、常见 token 参数、手机号和邮箱会被替换为 `[masked]`。相同指纹在 5 秒内只产生一条消息并累计 `count`；服务端在 `count >= 5` 时生成 `H5观察-重复前端异常` 低风险观察标签。

## 内网 IP 和外网 IP

- 默认 `webrtc=false`，内网地址状态为 `disabled`。
- 显式开启后，SDK 最长等待约 1.5 秒读取不带 STUN 服务的 WebRTC host candidate，只保留私有 IPv4/IPv6。
- 浏览器用 mDNS 隐藏地址时返回 `masked`；没有能力或候选时返回 `unavailable`，不会用 `0.0.0.0` 冒充检测值。
- 外网 IP 不由页面 JavaScript 请求第三方服务，而由服务端从 TCP 来源地址识别。只有直接来源命中可信代理 CIDR 时，才解析 `Forwarded/X-Forwarded-For/X-Real-IP`。

可通过 `SynapAgent.getMetrics().networkInfo` 查看内网地址探测状态。

## 服务端观察规则

所有新增 H5 规则当前均为观察模式。主要条件如下：

| Fact | 观察条件 | 标签 / 级别 |
| --- | --- | --- |
| `DeviceData` | UA 为空或包含 Headless/PhantomJS | `H5观察-异常UA` / MEDIUM |
| `DeviceData` | MuMu 或 Android x86 UA | `H5观察-模拟环境UA` / MEDIUM |
| `DeviceData` | 上报 UA 与 HTTP User-Agent 不一致 | `H5观察-UA不一致` / LOW |
| `SelfAppData` | 页面 host 不在 appId 白名单 | `H5观察-页面域名不一致` / MEDIUM |
| `RuntimeData` | `format=1` | `H5观察-代码格式化` / LOW |
| `RuntimeData` | 自动化信号总数至少 2 | `H5观察-运行环境自动化` / MEDIUM |
| `RuntimeData` | 只有 1 个自动化信号 | `H5观察-单一自动化特征` / LOW |
| `IntegrityData` | 加权完整性分数至少 2 | `H5观察-环境完整性` / MEDIUM |
| `ResourceIntegrityData` | 资源/宿主完整性布尔证据至少 2 个 | `H5观察-资源与宿主完整性` / MEDIUM |
| `ResourceIntegrityData` | 安全报告累计至少 5 条 | `H5观察-浏览器安全报告聚集` / LOW |
| `BehaviorData` | 至少 2 组自动化行为异常且达到最小样本量 | `H5观察-自动化行为` / MEDIUM |
| `ActionData` | 动作内事件数至少 2 且非可信事件至少 2 | `H5观察-业务动作非可信事件` / LOW |
| `SessionData` | 客户端时钟回拨 | `H5观察-客户端时钟回拨` / MEDIUM |
| `SessionData` | 并发标签页超过 3 | `H5观察-多标签并发` / LOW |
| `ErrorData` | 同指纹 `count >= 5` | `H5观察-重复前端异常` / LOW |
| `EventData` | `event.isTrusted=false` | `H5观察-非可信浏览器事件` / LOW |
| `NetworkData` | 至少 20 次请求且失败率至少 50% | `H5观察-接口失败突增` / LOW |
| `LocationData` | 上报速度大于 100 | `H5观察-异常移动速度` / LOW |
| `DebugData` / `DevToolData` | Fact 产生 | 调试暂停/开发工具 / LOW |

风险聚合输出包含 `detectorVersion=h5-risk-1`、`ruleVersion=2026-08-05`、`score`、`confidence`、`reasonCodes`、`evidenceCount`、`observation=true` 和 `trustLevel=sc1-authenticated/P256_HKDF_SHA256_AES256_GCM`。风险分数按会话衰减并结合业务 sequence、服务端时间差和可信网关信号；观察期内不应直接关联处罚。

## 验收测试用例

### TC-01：默认低侵入与静态 Fact 去重

1. 使用 `collectionProfile: 'low'` 初始化。
2. 观察页面是否弹出位置权限，并检查上传批次。
3. 触发多次周期采集或重新调用相同配置的 `init`。

预期：不请求位置、不启用 Canvas/WebGL/字体/WebRTC；同一 `startId` 只有一条完整 `DeviceData`，未变化的 `SelfAppData/RuntimeData` 不重复上报，timer 和 listener 不重复注册。

### TC-02：默认调试行为

1. 使用 `low` 初始化。
2. 按 F12 或 Ctrl/Command+Alt+I。
3. 打开停靠式 DevTools，令窗口内外尺寸差超过 200 像素。

预期：生成 `DevToolData`；相同快捷键 5 秒内冷却；服务端生成 `H5观察-开发工具` LOW 标签，不单独形成高风险结论。

### TC-03：代码格式化标签

分别构造 `RuntimeData.custom.format=1` 和 `format=0` 的协议测试消息。

预期：`format=1` 生成 `H5观察-代码格式化`、source `format:1`、级别 LOW，并映射 `CODE_FORMATTING_DETECTED`；`format=0` 不生成该标签。客户端重新格式化产物测试应校验实际运行函数的 `toString()` 是否包含换行，不能用 DevTools Pretty print 代替。

### TC-04：自动化和环境一致性

1. 在自动化浏览器中设置 `navigator.webdriver=true`，或模拟 Headless UA。
2. 分别制造 UA/platform、UA-CH/mobile 和触摸点不一致。
3. 单独篡改 fetch、XHR、EventTarget、appKey 或策略对象。

预期：生成 `RuntimeData/IntegrityData`；完整性证据按权重累计，单一低置信度信号只观察，多信号达到阈值后生成对应标签。

### TC-05：资源与宿主完整性

1. 从非白名单 origin 加载 SDK，或配置错误的 `expectedScriptIntegrity`。
2. 在非白名单 iframe 中加载。
3. 注册非白名单 Service Worker controller。

预期：`ResourceIntegrityData.signals` 标记具体异常；至少两个证据时服务端生成 `H5观察-资源与宿主完整性`。

### TC-06：CSP、资源错误和 ReportingObserver

1. 触发 CSP violation。
2. 加载不存在的 script/img/link。
3. 连续产生至少 5 条相同或聚合安全报告。

预期：`ResourceIntegrityData.reports` 只包含类别、路径模板、摘要和计数；不包含 query；累计达到 5 时生成 `H5观察-浏览器安全报告聚集`。

### TC-07：ErrorData 具体错误与脱敏

1. 5 秒内重复抛出 5 次相同 JS Error。
2. 触发 unhandled rejection、资源加载失败和 CSP violation。
3. 在错误文本或 URL 中加入测试 token、手机号、邮箱、query 和 fragment。

预期：相同错误合并为一条 `count=5` 的 `ErrorData`；字段包含 `from/category/message/templateHash/source/lineno/colno/count`；敏感文本被替换、source 无 query/fragment；服务端生成重复前端异常 LOW 标签。

### TC-08：行为聚合和语义去重

1. 正常移动、点击、输入至少 10 秒。
2. 模拟固定直线、固定时间间隔、高速点击和 `isTrusted=false` 事件。
3. 在触摸后 700 毫秒内触发兼容 click。

预期：只上传窗口统计，不包含输入值和完整轨迹；逐条 EventData 不重复发送触摸/鼠标兼容事件流，BehaviorData 只保留聚合计数；至少两类异常且满足最小样本量后才生成自动化行为标签。

### TC-09：业务动作窗口

```js
const id = crypto.randomUUID();
SynapAgent.markAction({ id, name: 'login', phase: 'start' });
// 执行业务动作，不传表单内容
SynapAgent.markAction({ id, name: 'login', phase: 'success' });
```

预期：产生一条 `ActionData`，动作 ID 只上传摘要，数据仅包含动作名称、阶段、耗时和行为计数；错误阶段、空 ID 或无法匹配的结束动作返回 `false`。

### TC-10：会话、BFCache、时钟和多标签页

1. 切换前后台和焦点，通过历史导航触发 BFCache。
2. 同 app key 打开至少 4 个标签页。
3. 在测试环境模拟系统时间回拨。

预期：状态边沿产生 `SessionData`；后台期间行为窗口重置；回拨和超过 3 个并发标签页分别生成对应观察标签。

### TC-11：可选网络监控

1. 显式设置 `network:true`。
2. 对同一路径模板发起至少 20 个 fetch/XHR/Beacon/WebSocket/EventSource 请求，其中至少 50% 失败。
3. 请求中加入 query、body、header 和敏感参数。

预期：只上报路径模板、传输类型、状态分组、数量和耗时；排除探针自身五个接口；不上传 query/body/header；满足阈值后生成接口失败突增标签。

### TC-12：位置采集

1. 默认档位初始化，确认不弹权限。
2. 显式设置 `location:true` 并分别模拟授权、拒绝和不可用。
3. 分别模拟授权返回有效坐标、拒绝授权和浏览器不支持；确认不会持续调用位置 API。

预期：仅显式开启后调用一次 `getCurrentPosition`；获得有效坐标时产生 `LocationData`；拒绝或不支持时不上传精确坐标，也不持续跟踪。若宿主或后续实现更新了位置状态，只有移动 100 米、精度变化 50 米或超过 60 秒才允许重报。

### TC-13：内网和外网 IP

1. 默认初始化并读取 `getMetrics().networkInfo`。
2. 设置 `webrtc:true`，分别模拟私有 candidate、mDNS candidate 和无 candidate。
3. 通过可信和非可信代理分别提交伪造转发头。

预期：默认 `disabled`；开启后分别得到私有地址、`masked`、`unavailable`，从不返回占位 `0.0.0.0`；服务端忽略非可信来源的转发头，并用可信连接地址覆盖 `common.wanIp`。

### TC-14：ACK、幂等和 sequence

覆盖响应超时、断开、空响应、错误密文、错误 JSON、`status=0`、batchId 不一致、部分拒绝、同批重复、跨批重复和页面恢复。

预期：重试时 `messageId/sequence` 不变；新入队消息不被旧 ACK 清除；已完成消息只运行一次规则并只产生一个有效 Kafka Checkpoint；sequence 缺口和倒序进入风险证据。

### TC-15：协议、Origin 和结构校验

分别提交缺少 upload meta、ACK、messageId、sequence、observedAt，错误 protocolVersion，非白名单 Origin，不一致的 Origin/Referer/Sec-Fetch、超过 24 个 common 字段、过多 Fact、过长字符串或过深嵌套。

预期：格式和权限错误永久拒绝，不进入无限重试；客户端只访问本文列出的五个固定接口。

### TC-16：生命周期、存储降级和严格 CSP

1. 禁用 Cookie、localStorage、sessionStorage。
2. 使用不允许 `unsafe-eval`、Blob Worker 的严格 CSP。
3. 初始化、销毁、再次初始化，并覆盖离线和页面隐藏恢复。

预期：SDK 失败开放且不因存储/CSP 中断；`destroy` 后无探针 timer/listener/Worker；待发批次恢复时保持消息元数据。

### TC-17：公共 API

验证 `SynapAgent.init/destroy/flush/userData/markAction/getDeviceInfo/getRatingInfo/getLabelInfo/getMetrics`。

预期：查询接口返回 Promise；`window.deviceInfo/ratingInfo/labelInfo` 未定义；`userData` 拒绝空标识、不可序列化或超过限制的数据；重复初始化幂等。

## 安全和隐私边界

- `appId` 是公开标识；H5 身份依赖 HTTPS、服务端公钥固定、Origin 白名单和不可导出的 WebCrypto 安装密钥，强度低于原生端的一次性令牌注册。
- 客户端信号可被同页脚本修改，任何单一客户端信号都不应直接判定高风险。
- 不采集摄像头、麦克风、通讯录、剪贴板、原始键盘内容、完整行为轨迹、浏览历史、扩展枚举或隐身模式。
- `EventData` 保留点击坐标和输入类型，但不包含输入值；对业务仍属非必要时，可通过服务端策略移除对应事件。
- 精确位置、Canvas、WebGL、字体、WebRTC 和业务网络监控必须由宿主显式开启并完成告知或授权。
- 新规则默认 `observation=true`；完成真实浏览器支持率、触发率和误报率评估前，不关联处罚。
